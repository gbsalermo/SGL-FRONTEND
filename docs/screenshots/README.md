# Screenshots aprovados

Esta pasta guarda imagens de apresentação das interfaces já validadas do SGL.

## Login

Salvar o screenshot final aprovado como:

```text
docs/screenshots/login-final.png
```

O `README.md` da raiz já referencia exatamente esse caminho:

```markdown
<img src="docs/screenshots/login-final.png" alt="Tela final de Login do SGL" width="100%">
```

Ao substituir a captura por uma versão mais recente, manter o mesmo nome para evitar alterar o README.
